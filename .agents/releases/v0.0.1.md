# mlx-timesfm 0.0.1

Initial alpha release of the TimesFM 3.0 inference stack for Apple MLX.

## Highlights

- Native MLX model, transformer, normalization, masking, and forecast decode.
- Direct loading of the original 445-tensor FP32 checkpoint with `mx.load()`.
- Univariate and multivariate targets, past-only and past/future covariates,
  nine forecast quantiles, masking, detrending, stitching, and iterative RevIN.
- Full-FP32 correctness policy and MLX CPU/GPU regression against a versioned
  real-data oracle.
- MLX-only runtime and tests: PyTorch is not a package or development dependency.

## Validation

- 46 project tests pass with the original checkpoint.
- Wheel and source distribution pass content, metadata, Twine, and isolated
  installation checks.
- CI validates Apple-silicon macOS and Ubuntu before Trusted Publishing runs.

The official TimesFM 3.0 checkpoint is not bundled. Google distributes those
weights separately under the TimesFM Non-Commercial License v1.0, restricting
them to non-commercial, non-production use. The package source is Apache-2.0.
